# Feature matrix

- Installation: Frappe/ERPNext v16; installer-owned schema and separately provisioned mapping schema.
- Read operations: validated source binding, schema snapshot, active mapping and approved read service.
- Migration: employees, contacts, projects, events, tasks, documents, pictures, articles and services.
- Relationships: source-bound identities, deferred linking and conflict-safe reconciliation.
- Assignments: verified active User bindings, explicit policy and framework concurrency boundary; historical identities remain references.
- Mapping: personal drafts, revisions, directional exchange, schema compatibility and publication controls.
- Project histories: mapped source entries, pagination, visibility and deduplication.
- Outbound writes: separately approved contracts, permissions, preview, confirmation and verified readback.
- Operations: manual runs, bounded test runs, checkpoints, polling and recovery controls.
- Helpdesk/CRM: native ERPNext references and duplicate-mirror guards.
- Verification: source tests do not establish target-site configuration, authorization or external execution.
